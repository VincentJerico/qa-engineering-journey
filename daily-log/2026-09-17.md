## What I learned
- `git init` is purely local; the GitHub account only matters at push time, based on the active credentials.
- `gh auth` can hold multiple accounts — `gh auth switch --user <name>` selects the active one, which keeps personal and work repos separate.
- Draft "expected results" are guesses until executed — several error messages differed from what I wrote, so executing tightens the cases.
- Verifying via the DOM (element counts, prices, image `src`, badge text) is more reliable than eyeballing screenshots, and it's how I proved BUG-001 and the tax math.
- A "behavior-documentation" case (empty-cart checkout) is worth writing — it's exactly how I found BUG-002.
